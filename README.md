## Featured Projects

### [Enterprise RAG Engineering Platform](https://github.com/Ashtro30/rag-engineering-platform)

A multi-tenant retrieval-augmented generation platform developed across milestones, with a focus on secure retrieval and multi-hop reasoning.

- Tenant-aware access controls and pre-retrieval filtering
- Semantic caching with tenant and version-aware keys
- Query complexity routing, hybrid retrieval, reranking, and GraphRAG
- Audit logging and telemetry

**Technologies:** Python · Qdrant · LiteLLM · NetworkX · JWT · SQLite · Streamlit

### [LifeLink — AI-assisted Donor Matching](https://github.com/Ashtro30/LifeLink)

A healthcare-focused prototype that helps hospitals identify compatible, nearby, available blood donors, forecast demand, and manage organ-donation awareness and consent records.

- Explainable donor ranking using compatibility, proximity, availability, and eligibility
- Hospital inventory and emergency-request workflows
- Blood-demand forecasting with baseline and machine-learning models
- Role-based access and privacy-conscious donor information handling

**Technologies:** Next.js · React · TypeScript · MySQL · Python · scikit-learn

> LifeLink is a prototype and decision-support project, not a medical device. Medical eligibility and compatibility decisions require qualified clinical review. Its organ module records consent and does not allocate or match organs.
